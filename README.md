# Web Search MCP Server

**DuckDuckGo search + web content extraction for AI agents.** No API key needed.

## Quick Install (for any agent)

```json
{
  "mcpServers": {
    "web-search": {
      "command": "npx",
      "args": ["-y", "@tiagohanna/web-search-mcp"]
    }
  }
}
```

## Tools

### `web_search`
Search DuckDuckGo and get up to 10 results with titles, URLs, and snippets.

### `web_fetch`
Fetch any URL and extract its readable content (strips ads, nav, footers).
